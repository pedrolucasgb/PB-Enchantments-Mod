Every tree gates behind real in-game achievements — mine the ores, fell the trees, land the shots — then spend XP levels to unlock perks and stamp exclusive enchantments on your gear. Press K in game to open the trees, or use /pbenchants.

How to install

  1. Install the Fabric Loader for Minecraft 26.2 (run the installer, pick 26.2, done).
  2. Drop Fabric API and the downloaded pbenchants.jar into your .minecraft/mods folder.
  3. Launch the fabric-loader-26.2 profile and press K in game.

Prefer one click? Grab the automatic installer — it sets up Fabric, Fabric API and the mod for you.
