# 0.10.0 — version note draft & backlog

Target release: **v0.10.0-beta**. This document is the working note for the release: what has
already landed on `main` since v0.9.0-beta, and everything Pedro has queued for this version.
When the version is tagged, the `patch-notes` skill turns the shipped subset of this list into
the trilingual `docs/patchnotes/0.10.0-beta.md`.

---

## Already merged since v0.9.0-beta

- **PR #61 — fix: Arcane Insight UI not rendering after resolution change.** UI building moved
  to a lifecycle that survives window/resolution changes.
- **PR #60 — chore: Discord announcement automation.** `release.yml` now posts each release to
  Discord through a webhook.

## Fixes (Correções)

1. **Seeker's Eye — keyboard focus leak.** Typing in the Seeker's Eye field (e.g. `T`) also
   reaches the recipe-book / crafting search bar, which breaks the inventory and crafting
   screens whether the player is searching or the item is locked. Clicking the magnifier must
   take a **total keyboard lock**: while active, every keystroke goes to the Seeker's Eye field
   and nowhere else.
2. **Path of the Arrow — Multishot volley-kills counter.** The counter only accepts hostile
   mobs but the text does not say so. The description/tracker must state "hostile mobs only".
3. **Harvest Swing + magnet.** When harvesting sugar cane with Harvest Swing, the magnet
   sometimes misses drops and canes fall on the ground. All drops from a Harvest Swing break
   must be pulled to the inventory.
4. **Enchanting table must respect unlocks.** Protection V, Power VI, Looting IV, Fortune IV —
   and any other mod-gated enchantment — must **not appear as enchanting-table options** for a
   player who has not unlocked them. Villager trades may still offer them.

## Changes (Mudanças)

- **Artisan — Shulker Sight:** right-clicking a shulker box in the inventory also opens it
  (same as the current open gesture).
- **Skill UI scroll bar:** any tier or node description too long for the panel gets a scroll
  bar instead of overflowing/clipping.
- **Indestructible (upgrade):** besides never losing durability, the item becomes immune to
  lava, explosions, cactus — anything that destroys the item entity. It still despawns by the
  normal 5-minute timer.
- **Remove the Waypoint Stone node** (`waypoint`, Explorer tree — `SkillTrees.java:507`),
  including its perk code (`perk/Waypoints.java`), lang keys and any references.
- **Echo-shard cost rebalance:**
  - Reaper's Wisdom: **4 → 2** echo shards (`SkillTrees.java:409`)
  - Nostalgy IV: **8 → 4** echo shards (`SkillTrees.java:757`)
  - Death Eyes: **8 → 10** echo shards (`SkillTrees.java:764`)

## Features

### Artisan Tier 5 — Third Eye
- Unlock cost themed on glowing items: spectral arrows, glow ink sacs and similar.
- Works like Seeker's Eye, but searches **nearby containers up to 2 chunks away**.
- A container holding the searched item glows with a **spectral-arrow-style outline** — that
  effect exists only for entities today, so we need an outline/glow renderer **for blocks**.
  Research existing approaches (glowing fake entity trick, custom outline render layer);
  the outline must respect the block's actual shape.
- Must work for **any block that stores items**: chests, placed shulker boxes, furnaces,
  hoppers, barrels, etc.

### Explorer Tier 4 — Portable Ender Chest
- Open the ender chest from the inventory via a mini chest button, or with `/echest`.

### Explorer Tier 5 — Double Ender Chest
- The ender chest becomes a double chest (54 slots).

### Indestructible on shulker boxes
- Shulker boxes become valid targets for the Indestructible enchantment.

### Anvil disenchant toggle
- New anvil toggle: **enchant (default) / disenchant**.
- Disenchanting requires an enchanted book whose enchantment **exactly matches** one present
  on the tool; only then does the disenchant option appear, and the player chooses which mode
  to apply.
